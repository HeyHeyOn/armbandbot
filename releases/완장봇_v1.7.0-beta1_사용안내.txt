완장봇 1.7.0-beta1 사용 안내
versionCode 188 / 2026-10-11

이번 베타의 변경
- 도배 방지를 같은 작성자 정보의 반복 글을 찾는 방식으로 개선했습니다. 짧은 시간에 글이 많다는 이유만으로 다른 작성자의 글까지 삭제하던 방식을 제거했습니다.
- 지정 시간 안에 비슷한 제목과 본문이 기준 횟수 이상 확인되면, 첫 글을 포함한 해당 반복 글들을 삭제합니다. 이미 지나간 글은 다음 검사 주기에 다시 확인하므로 삭제 시점에 차이가 있을 수 있습니다.
- 봇별·갤러리별로 따로 집계하고, 중복 검사로 횟수가 늘거나 오래된 기록이 남지 않도록 했습니다. 기준·대상·보호 목록 변경과 봇 중지/재시작 때 판정을 다시 시작합니다.
- 화이트리스트로 보호된 글과 글번호 예외는 반복 횟수와 삭제 대상에서 제외합니다.

설정 방법
봇 상세 → 필터 → 도배 방지
1. 도배 방지 사용을 켭니다.
2. 반복 시간, 횟수, 유사도 기준을 입력한 다음 ‘기준 저장’을 누릅니다.
   기본값: 최근 10분 / 4개 이상 / 유사도 85%
   조절 범위: 1~60분 / 2~20개 / 85~100%
   ‘기본값 불러오기’는 입력값을 되돌립니다. 실제 적용하려면 ‘기준 저장’을 누르세요.
3. 대상인 유동·깡계를 선택합니다. 깡계는 기존 깡계 판정 기준을 따릅니다.
4. ‘삭제 없이 감지 기록만’을 켜면 이 기능은 삭제 대신 보류 기록을 남깁니다. 다른 필터의 처리는 해당 필터 설정을 따릅니다.

판정 범위
- 유동은 공개된 IP 정보, 회원은 ID로 묶습니다. 공개 IP가 같다고 한 사람임이 보장되지는 않으므로 제목과 본문도 함께 비교합니다. IP 자체를 이용 제한하지 않습니다.
- 공백·일반적인 특수문자·일부 보이지 않는 문자를 정리해 비교합니다. 100%도 정리된 텍스트의 일치를 뜻하며 원문 바이트 일치는 아닙니다.
- 숫자나 일부 부정 표현이 다르면 다른 내용으로 취급합니다. 짧은 문장은 정리 후 완전히 같아야 하며, 제목과 본문을 합쳐 의미 있는 글자가 8개 미만이면 제외합니다.
- 이미지·동영상만 있고 본문 텍스트가 없는 글, 비교 필드가 8,192자를 초과하는 글, 작성 시각을 확인할 수 없는 글은 제외합니다.
- 현재 봇의 탐색 범위와 실행 시간 안에서 발견한 글을 집계합니다. 여러 탭을 함께 탐색하면 같은 갤러리의 반복 글을 함께 집계하지만, 탐색하지 않는 페이지까지 찾아가지는 않습니다.
- 봇마다 최근 기록을 최대 1,000개 유지합니다. IP 변경, 크게 바꾼 문구, 이미지 속 글자까지 판정하는 기능은 아닙니다.

업데이트
기존 앱 위에 설치할 수 있으며 패키지와 서명은 유지합니다. 설치 전 설정 백업을 권장합니다. 기존 도배 방지 사용 여부와 대상 선택은 유지되지만, 판정 방식은 이번 반복 글 기준으로 바뀝니다. 이전의 수집 개수 설정을 새 시간 기준으로 잘못 가져오지 않도록 새 기준은 기본값으로 시작합니다.

베타 검증
Android 7·15 에뮬레이터에서 자동 계측 각각 20개와 실제 배포용 APK의 업데이트·화면·설정·DB·스냅샷 보존 검사 각각 24개가 통과했습니다.
완장봇 미니갤 테스트 탭의 소유 글 3개로 보호 목록·감지 기록·최초 글 포함 반복 글 삭제·정상 글 보존을 확인하고 모두 정리했습니다. 게시 간격을 충분히 두기 위해 실서버 검증 기준은 60분/2개/100%를 사용했고 기본값과 경계값은 로컬 테스트로 확인했습니다.
