완장봇 1.5.4-beta2 사용 안내

바뀐 화면
- 봇 상세 화면에 ‘관리 자동화’를 추가했습니다. 갤러리 설정 자동 갱신, 예약 끌올, 자동 탭 분류를 각각 따로 설정합니다.
- ‘원격 목록’은 ‘기본 탐색 설정’에서 바로 들어갑니다.
- 봇 상세 화면에서는 오른쪽 스위치로 켜고 끕니다. 항목 이름을 누르면 해당 기능의 상세 설정이 열립니다.
- 긴 설명과 목록 형식 안내는 각 상세 화면 오른쪽 위의 도움말(?)로 옮겼습니다.

설정 방법
- 예약 끌올: 게시글 주소와 매일 실행할 시각을 입력하고 예약 추가/수정을 누릅니다.
- 자동 탭 분류: 관리할 갤러리의 탭을 불러온 뒤 키워드와 대상 탭을 선택하고 규칙 추가/수정을 누릅니다.
- 원격 목록: GitHub 또는 Google Sheets 등의 목록 주소와 갱신 간격을 저장합니다. ‘지금 갱신’으로 수신 결과를 확인할 수 있습니다.

기존 예약·분류 규칙·원격 주소·로컬 목록을 유지합니다. 끄더라도 설정은 지우지 않습니다. 아직 설정하지 않은 기능을 켜면 설정 안내가 나옵니다.

개발용 베타입니다. 설치 전 DB를 백업하세요. 실제 끌올·탭 분류는 관리 권한이 있는 갤러리에서 사용하며, 봇이 실행 중이어야 작동합니다. 절전·강제 종료·로그인 만료 상황의 정시 실행을 보장하지는 않습니다.
