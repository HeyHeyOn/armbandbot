# 완장봇 v1.5.2-beta2 사용 안내

> 개발용 베타입니다. API 24·35에서 최종 APK의 설정·DB 화면과 시간대 편집을 확인했습니다. 실제 계정 연동이나 장시간 운용을 보장하는 검증은 아닙니다.

기존 봇 설정과 데이터, 설정해 둔 작동 시간대는 유지됩니다. 기록을 지우기 전에는 DB를 백업하세요.

## 봇별 독립 검사 기록

봇 설정의 갤러리 새로고침 항목 아래에 **독립 검사 기록 사용**과 **작동 시간대**가 있습니다. 독립 검사 기록 설정을 바꾸기 전에는 봇을 중지하세요.

- 독립 검사 기록을 켜면 검사 여부·댓글 수·스냅샷을 봇별로 분리합니다.
- 처음 켤 때 **공용 검사 상태에서 시작**하면 기존 공용 기록을 이어 쓰고, **빈 기록으로 시작**하면 검사 범위 안의 기존 글도 다시 검사할 수 있습니다.
- 옵션을 꺼도 독립 기록은 남습니다. 다시 켤 때 이어 쓰거나 공용 기록 기준으로 다시 초기화할 수 있습니다.
- 봇을 복사하거나 설정을 새 봇으로 가져오면 독립 검사 옵션은 꺼진 상태로 시작합니다.

차단·삭제·보류 결과와 중복 조치 방지는 공용입니다. 독립 기록을 켠다고 같은 대상에 조치를 반복하는 것은 아닙니다.

## 하루에 여러 작동 시간대 설정

작동 시간대를 켜고 구간을 추가하세요. 번호가 붙은 각 구간의 시작·종료 시각을 수정하거나 구간을 삭제할 수 있습니다. 구간은 최대 64개이며, 휴대폰에 설정된 현지 시간을 기준으로 매일 반복합니다.

- `22:00~05:00`: 밤 10시부터 다음 날 새벽 5시까지 작동합니다.
- `10:00~11:00` + `15:00~16:00`: 두 구간에만 작동하며, 사이의 `11:00~15:00`에는 대기합니다.
- 겹치거나 맞닿는 구간은 끊김 없이 이어서 작동하며, 겹친 시간에 검사를 중복 실행하지 않습니다.
- 시작 시각부터 작동하고 종료 시각부터 대기합니다. 시작과 종료 시각이 같은 구간은 저장할 수 없습니다. 하루 종일 작동하려면 시간대 옵션을 끄세요.

시간대 밖에는 실행 스위치를 켠 채 **예약 대기**합니다. 직접 중지한 봇을 자동으로 켜는 기능은 아닙니다. 시간대가 끝나면 새 검사·조치를 시작하지 않으며, 이미 서버에 보낸 조치는 결과를 기록합니다.

휴대폰의 시간·시간대 또는 일정 변경은 실행 중인 서비스에서 최대 60초 간격으로 다시 확인합니다. Android가 앱 실행을 제한하거나 서비스를 종료하면 정확한 시각의 재개를 보장할 수 없습니다. 복구 안내 알림이 뜨면 앱을 다시 시작하세요. 대기 중 작성된 글은 재개 시 설정된 검사 범위를 벗어나면 검사하지 못할 수 있습니다.

## DB 모니터링과 선택 초기화

- 갤러리 선택 아래의 **전체 / 공용 / 봇별 독립 기록** 탭에서 검사 기록을 나누어 봅니다. 전체는 모든 검사 기록, 공용은 함께 쓰는 기록, 봇별 탭은 해당 봇의 독립 기록을 보여줍니다.
- 봇 상세의 검사 목록은 해당 봇이 사용하는 공용 또는 독립 기록을 보여줍니다.
- **공용 또는 봇별 탭에서 초기화**하면 선택한 검사 범위 전체의 검사 기록을 지웁니다. 다른 검사 범위와 조치 기록은 보존됩니다. 갤러리·검색 필터나 체크한 행만 지우는 기능이 아니므로 확인창의 검사 범위를 확인하세요.
- **전체 탭에서 초기화**하면 모든 범위의 검사·차단·보류 기록, 조치 중복방지 정보와 스냅샷을 삭제합니다. 먼저 DB를 백업하세요.
- 개별 행 삭제와 범위 초기화는 별개입니다. 조치 이력 조회는 전체 또는 조치를 실행한 봇 기준으로 구분합니다.
- DB 백업은 현재 탭과 관계없이 공용·독립 기록과 조치 이력을 포함한 DB 전체를 저장합니다.

기존 DB의 검사 기록은 공용 기록으로 보존됩니다. 실행한 봇을 알 수 없는 기존 조치는 이전 기록으로 구분합니다.
