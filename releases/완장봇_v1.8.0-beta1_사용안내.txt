완장봇 1.8.0-beta1 사용 안내

■ 이번 베타
‘도배 방지’에 연속 작성 감지를 추가했습니다. 제목과 본문을 매번 바꿔도 같은 작성자 정보로 짧은 시간에 여러 글을 올리면 감지합니다.

■ 설정 방법
봇 상세 → 필터 → 도배 방지로 이동합니다.
1. ‘도배 방지 사용’을 켭니다.
2. ‘유사 내용 반복 감지’와 ‘연속 작성 감지’를 필요에 따라 각각 켜거나 끕니다.
3. 연속 작성 감지에서 유동(같은 표시 IP)과 깡계(같은 계정)의 확인 시간·작성 개수를 각각 정합니다.
   기본값: 유동 60초·10개 / 깡계 60초·5개
   입력 범위: 10~3,600초 / 2~100개
4. 연속 작성 감지의 개별 차단 설정에서 보류·삭제·차단을 선택합니다.

■ 기본 동작과 처리 범위
- 새 연속 작성 감지는 기본 꺼짐이며, 처음 켰을 때의 처리 방식은 보류입니다. 기존 유사 내용 반복 감지의 설정과 처리 방식은 유지됩니다.
- 보류는 글을 지우지 않고 기록을 남깁니다. 삭제로 바꾸면 조건을 채운 시간 범위의 첫 글부터 함께 삭제합니다.
- 같은 글을 다시 읽어도 한 개로 셉니다. 제목·본문·최소 글자 수는 연속 작성 감지의 개수 판단에 영향을 주지 않습니다.
- 같은 갤러리의 유동·깡계 게시글만 대상으로 합니다. 깡계는 깡계 필터의 판정 기준을 따릅니다. 일반 회원·댓글·화이트리스트 작성자·차단 예외 글은 집계에서 제외합니다.
- 두 감지에 함께 걸려도 같은 글에 조치를 중복 실행하지 않습니다. 한쪽이 보류이고 다른 쪽이 삭제·차단이면 삭제·차단 쪽을 따릅니다. 둘 다 삭제·차단이면 기존 유사 내용 반복 감지의 처리 방식을 우선합니다.
- 개별 차단 설정을 끄면 봇의 차단 기본 설정을 따릅니다. 기준·대상·관련 보호 설정을 바꾸거나 봇을 중지하면 모아 둔 감지 기록을 새로 시작합니다.

■ 주의사항
- 표시 IP는 여러 사람이 공유할 수 있습니다. 낮은 기준을 바로 삭제·차단에 적용하기보다 먼저 보류 결과를 확인하세요.
- 현재 탐색 범위에서 실제로 확인한 글만 셉니다. 검사 주기가 확인 시간보다 길면 시간 범위를 벗어난 글을 놓칠 수 있습니다. 이미 확인했던 첫 글은 다음 검사 때 처리되어 늦을 수 있습니다.
- IP·계정을 바꾸는 도배는 이 기능만으로 한 작성자로 묶지 못합니다.
- 기존 추천수 조작 방지 기능의 실제 개념글 해제 성공은 실서버 미검증 상태입니다. 이번 작성 빈도 검증과는 별개의 한계입니다.

■ 업데이트
중요한 설정·기록을 미리 백업하고 실행 중인 봇을 중지한 뒤, 기존 앱을 삭제하지 말고 새 APK를 덮어 설치하세요. Android 7.0 이상에서 사용할 수 있습니다.
