완장봇 1.6.0-beta3 사용 안내

이번 베타는 화면 구성만 새로 정리했습니다. 기능, 판정 방식, 저장된 설정은 바뀌지 않습니다.

1. 봇 상세 화면 – 하단 탭
봇을 누르면 화면 아래에 다섯 개의 탭이 나옵니다. 위쪽에는 봇 이름, 현재 상태(실행 중·예약 대기·중지됨·로그인 필요), 실행 스위치가 항상 보입니다.
- 홈: 관리 중인 갤러리, 최근 확인한 글 번호, 사용 중인 필터 수를 보여줍니다. 차단 필터·자동화 카드를 누르면 해당 탭으로 이동합니다. 아래 바로가기에서 활동 로그, 이 봇의 DB 기록, 설정 내보내기를 열 수 있습니다.
- 필터: 게시물 차단 필터와 고급 미디어 필터를 모았습니다. 스위치로 켜고 끄며, 항목을 누르면 세부 설정이 열립니다.
- 자동화: 작동 시간대와 관리 자동화(갤러리 설정 자동 갱신·예약 끌올·자동 탭 분류)를 모았습니다.
- 로그: 활동 로그입니다. 내보내기·디버그 정보 내보내기·로그 삭제는 오른쪽 위 ⋮ 메뉴로 옮겼습니다. 맨 위/맨 아래 이동 버튼은 그 옆에 있습니다.
- 설정: 관리할 갤러리, 탐색 속도, 개별 DB, 차단 후속 동작, 설정 내보내기, 시스템 관리(디버그 로그·개발자 설정·로그아웃·봇 삭제)를 모았습니다.

이전에 쓰던 항목은 이렇게 찾으세요.
- 기본 탐색 설정, 차단 후속 동작, 시스템 관리 → 설정 탭
- 게시물 차단 필터, 고급 미디어 필터 → 필터 탭
- 작동 시간대, 관리 자동화 → 자동화 탭
- 상단의 내보내기 버튼 → 설정 탭의 '설정 내보내기' 또는 홈 탭 바로가기

2. 봇 목록
봇마다 실행 상태를 색으로 표시합니다. 화면 아래에서 불러오기·DB 기록·봇 추가를 사용합니다. 다크/라이트 모드 전환과 도움말은 오른쪽 위 버튼으로 옮겼습니다. 길게 눌러 순서 변경, 왼쪽으로 밀어 내보내기/복사/삭제하는 방법은 그대로입니다.

3. 디자인 정리
관련 설정을 하나의 목록 카드로 묶고 아이콘·여백·글자 크기·색을 통일했습니다. 모든 상세 화면의 상단 모양을 같게 맞추고, 깡계 필터·도배 방지·AI 필터 화면 제목이 '상세 설정'으로 보이던 것을 고쳤습니다. 다크 모드에서도 대화상자·메뉴·상태바 아이콘이 앱의 설정을 따릅니다.

4. 설치
기존 앱을 지우지 말고 APK를 덮어 설치하세요. 같은 패키지와 서명을 사용하며, 버전 코드는 182입니다. 기존 봇·설정·DB·스냅샷을 유지합니다. 중요한 설정은 앱의 내보내기 기능으로 별도 보관할 수 있습니다.

5. 검증 범위
Debug·Release JVM 테스트 각각 699개를 통과했습니다. Android 7(API24)·Android 15(API35) 화면 테스트를 실행했고 결과는 별도 검증 JSON에 기록합니다. 정적 검사 오류는 없으며, 서명·DEX 검사와 배포용 APK의 이전 베타 업데이트·데이터 유지·밝은/어두운 화면을 두 Android 버전에서 확인했습니다.
화면 확인은 로그인하지 않은 시험용 봇으로 진행했습니다. 이번 검증에서 서버 게시·차단·삭제·자동 탭 이동은 실행하지 않았습니다. 기능 코드는 바꾸지 않았지만, 장시간 운용이나 사용 중인 모든 갤러리에서의 동작을 보장하는 검증은 아닙니다.
