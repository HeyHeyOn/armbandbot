# 완장봇 1.4.5-beta3

## 변경사항
- 우회 금지어 설정에 `영문 대소문자 우회 감지` 토글을 추가했습니다. 켜면 등록한 영문 금지어의 대문자와 소문자를 같은 문자로 검사합니다.
- 우회 금지어 설정에 `유니코드 문자 우회 감지` 토글을 추가했습니다. 켜면 전각 영문·숫자, 보이지 않는 문자, 일부 키릴·그리스·체로키 동형문자를 정규화해 검사합니다.
- 두 강화 옵션은 서로 독립적으로 켜고 끌 수 있으며, 기존 설정과 동작을 보존하기 위해 기본값은 꺼짐입니다.
- 게시글과 댓글에 동일한 우회 금지어 비교 규칙이 적용됩니다.
- 설정 내보내기와 가져오기에 두 강화 옵션이 포함됩니다.
- DB 백업에서 복원한 최초 스냅샷이 첫 재검사 결과로 바뀌던 문제를 수정했습니다. 복원된 최초본은 보존되고 첫 재검사 결과는 최신본으로 저장됩니다.

## 확인 방법
1. 봇 설정 → 필터 설정 → 금지어 → 우회 금지어 강화에서 원하는 옵션을 켭니다.
2. 대소문자 옵션은 `ABCD1234`를 등록한 뒤 `a.b-C.d1234`가 감지되는지 확인합니다.
3. 유니코드 옵션은 `ABCD`를 등록한 뒤 전각 `ＡＢＣＤ`가 감지되는지 확인합니다.
4. DB 복원 후 기존 스냅샷이 있는 글을 재검사했을 때 최초/최신 전환이 바로 표시되고 최초본이 유지되는지 확인합니다.
