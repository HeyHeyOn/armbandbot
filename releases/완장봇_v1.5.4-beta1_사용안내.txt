완장봇 1.5.4-beta1 사용 안내

새 기능
- 예약한 시간에 지정한 글을 끌올할 수 있습니다.
- 제목·본문의 키워드에 맞춰 글을 지정한 탭으로 옮길 수 있습니다.
- GitHub JSON 또는 Google Sheets CSV 목록을 불러와 기존 로컬 목록과 함께 사용할 수 있습니다.

설정 위치
봇 상세 설정 → 게시글 자동화 · 원격 목록

사용 방법
1. 예약 끌올: 관리 중인 갤러리의 글 주소와 시간을 입력하고 저장한 뒤 켭니다. 시간은 HH:mm 형식이며 여러 시간은 쉼표로 구분합니다.
2. 탭 이동: 탭 목록을 불러온 뒤 키워드와 목적지 탭을 선택해 저장하고 켭니다. 삭제·차단 처리와 사용자 예외·화이트리스트가 우선합니다.
3. 원격 목록: 원본 종류와 주소를 선택해 저장한 뒤 켭니다. 필요하면 '지금 불러오기'를 누릅니다.

원격 목록 형식
- GitHub: raw.githubusercontent.com의 JSON 주소를 사용합니다. 최상위에 version: 1과 lists를 둡니다.
- Google Sheets: 공개 CSV 주소를 사용하며 첫 행을 type,value로 둡니다. 시트 URL도 CSV 주소로 변환해 사용할 수 있습니다.
- 지원 종류: normal, bypass, user_blacklist, nickname_blacklist, nickname_bypass_blacklist
- 로컬 목록은 덮어쓰지 않고 함께 사용합니다. 불러오기에 실패하면 같은 원본의 마지막 정상 목록을 유지합니다.
- 앱은 시트의 공개 권한을 변경하지 않습니다. 비공개 시트나 로그인 필요한 주소는 사용할 수 없습니다.

주의
- 세 기능은 처음에는 꺼져 있으며 개별적으로 켜야 작동합니다.
- 끌올과 탭 이동은 관리 권한이 있는 마이너·미니 갤러리에서 사용합니다.
- 기능을 꺼도 저장한 규칙과 로컬 목록은 남습니다.
- 전송 결과가 불명확하거나 서버 확인에 실패한 조치는 중복 요청 방지를 위해 자동으로 재전송하지 않습니다. 처리 여부는 서버에서 확인해 주세요.
- 강제 종료·절전·로그인 만료 상태에서는 예약 시각의 실행을 보장하지 않습니다.
- 설정을 불러오거나 봇을 복사한 뒤에는 확인 후 기능을 직접 켜 주세요.
- 기존 버전 위에 설치할 수 있습니다. 베타 설치 전 중요한 DB는 백업해 주세요.
- 교차 갤러리 사용자 모니터링은 포함하지 않았습니다.
