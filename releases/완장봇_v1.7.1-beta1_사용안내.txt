완장봇 1.7.1-beta1 사용 안내

이번 베타의 변경 사항

1. 도배 방지의 최소 글자 수를 직접 입력할 수 있습니다.
- 봇 상세 → 필터 → 도배 방지 → 감지 기준 → 최소 글자 수를 누르세요.
- 기본값은 8자입니다. 0으로 저장하면 길이 제한 없이 검사합니다.
- 제목과 본문에 각각 적용하며, 공백·기호를 정리한 뒤 글자 수를 셉니다.
- 0일 때는 짧은 글과 기호만 있는 글도 비교합니다. 빈 본문끼리 같다는 이유로 서로 다른 글을 묶지는 않습니다.
- 입력 창에서 저장하면 적용되고, 취소하면 기존 값을 유지합니다. ‘기본값으로’에는 최소 글자 수도 포함됩니다.

2. 제목 또는 본문 중 한쪽만 반복되어도 감지합니다.
- 같은 갤러리·같은 작성자 정보의 글에서 제목끼리, 본문끼리 따로 비교합니다.
- 한쪽이 설정한 시간·반복 횟수·유사도 기준을 만족하면 첫 글을 포함해 기존에 선택한 삭제·차단·보류 방식으로 처리합니다.
- 제목을 반복하고 본문을 다르게 바꾸는 경우, 본문을 반복하고 제목을 바꾸는 경우를 모두 검사합니다.
- 제목 2개와 본문 2개를 섞어 반복 횟수 4개로 세지는 않습니다.
- 본문이 이미지·동영상뿐이어도 제목 반복을 검사합니다. 이미지 속 글자를 읽는 기능은 아닙니다.

3. 고정된 글자 수 제한을 정리했습니다.
- 20자 미만이면 완전히 같아야만 감지되던 제한을 없애 짧은 글에도 선택한 유사도를 적용합니다.
- 긴 본문 때문에 제목까지 검사에서 제외되던 제한도 없앴습니다. 긴 글을 잘라 같은 글로 취급하지 않습니다.
- 설정한 최소 글자 수는 백업 내보내기·가져오기·봇 복사에서도 유지됩니다. 이전 설정에서 이 항목이 없으면 8자로 시작합니다.

기본 기준
최소 8자 / 10분 안에 4개 / 유사도 85%
최소 글자 수 0은 길이 제한을 해제하는 값입니다. 설정된 검사 대상·화이트리스트·차단 예외·탐색 범위·반복 횟수 조건은 그대로 적용됩니다.

설치
기존 설정을 백업한 뒤 APK를 내려받아 기존 앱 위에 업데이트로 설치하세요. 기존 앱을 삭제할 필요가 없습니다.
앱 표시 버전: 1.7.1-beta1 (versionCode 191)
이번 배포는 개발용 베타입니다. 정식판은 1.7.0을 유지합니다.

검증 범위와 한계
Debug·Release JVM 테스트 각각 760개, Android 7·15 계측 각각 38개가 실패·건너뜀 없이 통과했습니다. 최종 서명 APK로 1.7.0에서 업데이트하고 설정·DB 기록·스냅샷 보존과 양 테마의 새 입력창을 확인했습니다. 상세 결과는 검증 원장을 참고하세요.
실제 갤러리에 게시글을 작성하거나 삭제·차단하는 시험은 이번 베타에서 추가로 수행하지 않았습니다. 물리 기기와 장시간 상시 운영은 별도 확인이 필요합니다.
