완장봇 1.6.0-beta2 사용 안내

1. 상세 화면 통일
예약 끌올과 자동 탭 분류의 상단 배경, 뒤로가기 화살표, 제목을 기존 필터 상세 화면과 같은 형태로 맞췄습니다.

2. 자동 탭 분류
관리 갤러리를 고른 뒤 이동할 탭을 선택하세요.
일반 키워드 또는 우회 키워드 카드를 누르면 큰 입력창이 열립니다. 키워드를 한 줄에 하나씩 입력하고 확인한 다음, 규칙 추가 또는 수정 저장을 눌러야 규칙이 저장됩니다.
- 일반 키워드: 입력한 문자열이 제목·본문에 그대로 포함되면 감지합니다. 예: 사과는 '맛있는 사과'에 일치하지만 '사. 과'에는 일치하지 않습니다. 영문 대소문자는 구분하지 않습니다.
- 우회 키워드: 기존 우회 금지어의 기본 판정과 같이 글자 사이 공백·특수문자를 포함해도 감지합니다. 예: 사과 → 사. 과
- 두 목록 중 하나만 입력해도 됩니다. 어느 목록이든 하나의 키워드가 일치하면 해당 규칙을 적용합니다.
- 키워드의 # 등 특수문자는 입력한 문자 그대로 저장합니다. 주석으로 처리하지 않습니다.
- 같은 갤러리의 규칙은 저장된 순서대로 확인하여 처음 일치한 규칙을 적용합니다.
- 기존 단일 키워드는 일반 키워드로 유지됩니다. 기존 규칙과 비활성 상태도 보존됩니다.
- 갤러리를 바꾸면 아직 저장하지 않은 규칙 초안은 취소됩니다. 팝업 취소 또는 수정 취소는 저장된 규칙을 바꾸지 않습니다.
- 규칙을 저장한 뒤 자동 탭 분류 사용을 켜세요. 봇 작동 중에만 실행됩니다.

화이트리스트·예외 글은 보호하고, 삭제·차단·검토를 우선합니다. 댓글은 분류하지 않습니다. 탭 설정에 따라 개념글 지정이 해제될 수 있습니다. 이전 베타의 관리 권한 인식 수정도 포함되어 있습니다.

3. 금지어·유동 필터 마스터 토글
봇 상세 목록의 금지어 필터·유동 필터 행에서 바로 켜고 끌 수 있습니다. 각 상세 화면 최상단에도 같은 토글이 있습니다.
끄면 하위 설정이 흐려지고 편집할 수 없으며 해당 필터 검사를 중지합니다. 입력한 목록·하위 옵션·개별 차단 설정은 삭제하지 않습니다. 다시 켜면 저장된 설정으로 재개합니다.
업데이트 직후 기존 동작을 유지하기 위해 두 마스터의 기본값은 켜짐입니다. 설정 복사·백업·가져오기에도 켜짐/꺼짐 상태가 포함됩니다.

4. 설치
기존 앱을 지우지 말고 APK를 덮어 설치하세요. 같은 패키지와 서명을 사용하며, 버전 코드는 181입니다. 기존 봇·설정·DB·스냅샷을 유지합니다. 중요한 설정은 앱의 백업 기능으로 별도 보관할 수 있습니다.

5. 검증 범위
Debug·Release JVM 테스트 각각 699개, Android 7(API24)·Android 15(API35) 화면 테스트 각각 21개를 통과했습니다. 정적 검사 오류는 없으며, 서명·DEX 검사와 배포용 APK의 이전 베타 업데이트·밝은/어두운 화면·설정/DB/스냅샷 보존을 확인했습니다. 상세 결과는 별도 검증 JSON에 기록합니다.
실제 laboratory1 관리 세션으로 탭 목록 조회와 비활성 규칙 저장을 확인했습니다. 이번 검증에서 서버 게시·차단·삭제·자동 탭 이동은 실행하지 않습니다. 장시간 운용이나 사용 중인 모든 갤러리에서의 동작을 보장하는 검증은 아닙니다.
