완장봇 1.7.0-beta2 사용 안내
versionCode 189 / 2026-10-11

이번 베타의 변경
도배 방지 설정 화면을 알아보기 쉽게 다시 만들었습니다. 반복 글을 찾는 판정 방식은 beta1과 같습니다.

1. 지금 설정을 한 문장으로 보여 줍니다
화면 위쪽에 현재 설정이 실제로 어떻게 작동하는지 표시합니다.
예: "같은 작성자가 10분 안에 비슷한 글을 4개 이상 올리면 첫 글까지 모두 삭제합니다."
검사 대상(유동·깡계)을 모두 끄면 감지하지 않는다는 경고가 대신 나옵니다.

2. 숫자는 −/+ 버튼으로 바꾸고 바로 저장됩니다
'기준 저장' 버튼을 없앴습니다. 확인 시간·반복 횟수·내용 비슷한 정도를 −/+로 바꾸면 그 즉시 적용됩니다.
- 확인 시간: 1~10분은 1분 단위, 그 이상은 5분 단위로 60분까지
- 반복 횟수: 2~20개
- 내용 비슷한 정도: 85·90·95·100%
'기본값으로'를 누르면 10분 · 4개 · 85%로 되돌아갑니다. 이전에 저장한 다른 값(예: 17분, 96%)은 그대로 유지되며, −/+를 누르면 가까운 단계로 이동합니다.
기준을 바꾸면 그동안 모은 반복 기록은 새로 시작합니다.

3. 처리 방식을 다른 필터처럼 고릅니다
다른 필터와 같은 '개별 차단 설정' 블록을 넣었습니다. 처리 방식을 삭제·차단·보류 중에서 고르고, 차단을 고르면 차단 기간·글/댓글 함께 삭제·차단 사유를 정할 수 있습니다. '개별 차단 설정 사용'을 끄면 '차단 기본 설정'을 따릅니다.
- 처음 값은 '개별 차단 설정 사용: 켜짐 / 처리 방식: 삭제'로, 지금까지와 같습니다. 차단 기본 설정이 차단이어도 업데이트만으로 차단이 시작되지 않습니다.
- beta1에서 '삭제 없이 감지 기록만'을 켜 두었다면 처리 방식이 '보류'로 바뀌어 같은 동작을 이어갑니다. 이 스위치는 처리 방식의 '보류'로 합쳐져 없어졌습니다.
- 보류는 글을 지우지 않고 기록만 남기며, 같은 글이 다른 필터에도 걸리면 그 필터의 처리 방식을 따릅니다.
- 차단은 첫 글을 포함해 반복된 글마다 요청합니다. 처음에는 보류로 결과를 확인한 뒤 바꾸는 것을 권장합니다.

4. 화면 정리
- '감지 기준 / 검사 대상 / 개별 차단 설정'으로 나누고 다른 필터 화면과 같은 모양으로 맞췄습니다.
- 깡계 항목에 현재 깡계 판정 기준을 함께 표시합니다.
- 도움말을 '감지 방식과 주의사항'에서 항목별로 볼 수 있습니다.
- 필터 탭의 도배 방지 아이콘을 스팸코드 필터와 구분되는 반복 아이콘으로 바꿨습니다.

설정 위치
봇 화면 → 필터 탭 → 도배 방지

업데이트
기존 앱 위에 설치할 수 있으며 패키지와 서명은 유지합니다. 도배 방지 사용 여부·기준·대상과 다른 설정은 그대로 유지됩니다. 설정 내보내기/가져오기에 도배 방지의 처리 방식도 포함됩니다. 설치 전 설정 백업을 권장합니다.

베타 검증
자세한 결과는 같은 버전의 검증 원장(완장봇_v1.7.0-beta2_검증.json)을 참고하세요. 이번 베타에서는 실제 갤러리 글 삭제·차단을 다시 시험하지 않았습니다. 반복 글 판정은 beta1에서 실서버로 확인한 것과 같은 코드이며, 처리 방식 선택(삭제·차단·보류)은 다른 필터와 같은 처리 경로를 사용합니다.
