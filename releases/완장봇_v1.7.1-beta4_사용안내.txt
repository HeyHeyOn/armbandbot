완장봇 1.7.1-beta4 사용 안내

이번 수정
마이너 갤러리의 개념글 관리 버튼을 인식하지 못해 상태·권한 확인 오류가 나던 문제를 수정했습니다. 미니 갤러리의 기존 관리 버튼 인식과 보호 조건을 유지합니다.

추천수 조작 방지
봇 상세 → 자동화 → 추천수 조작 방지에서 켤 수 있습니다. 기본은 꺼짐이며, 기준은 3분(180초) 동안 추천 10개 이상 증가입니다. 감지 기준 설정에서 시간(10~3,600초)과 증가량(1~1,000,000개)을 직접 바꿀 수 있습니다.

봇 안에서 추천 수를 별도로 관측합니다. 기본 약30초, 짧은 기준 시간에서는 최소5초 간격이며, 일반 게시물·댓글 검사 사이클의 대기시간과 독립적으로 동작합니다. 현재 봇의 계정·탐색 URL·검색·페이지 범위·운영 시간대를 사용합니다. 범위가 넓거나 서버 응답이 늦으면 간격이 늘어날 수 있습니다. 봇 중지/기능OFF 시 관측도 멈춥니다.

시간과 판정
실제 관측한 시간과 추천 수만 비교합니다. 3분·10개 기준에서 2분 동안10개가 늘면 감지합니다. 2분 간격으로 0→6→12를 봤다면 4분 동안12개 증가이므로 3분 기준10개로 환산해 감지하지 않습니다. 첫 관측은 기준점만 만들며, 관측 공백이 기준 시간보다 길거나 추천이 감소하면 새로 관찰합니다. 설정·계정·대상이 바뀌거나 앱을 다시 시작한 경우도 기준점을 새로 만듭니다.

처리와 보호
조건을 충족한 글이 개념글인지 다시 확인한 뒤 개념글만 해제합니다. 글 삭제·이용자 차단은 하지 않습니다. 일반 글에서 먼저 감지했다면 감지 후 기준 시간 안에 개념글이 되는 경우에도 해제합니다. 이후에는 새 관측으로 판단합니다. 기존 활성화된 ID/IP·닉네임 화이트리스트, 차단 예외 글, 보류/기처리 보호를 적용합니다. 여러 봇의 같은 글에 대한 성공한 해제는 중복 실행하지 않으며, 서버 결과를 확인할 수 없는 경우 재요청을 보류합니다. 활동 로그에서 관측 시간·추천 증가량·해제 결과를 확인할 수 있습니다.

주의할 점
추천 급증만으로 실제 조작을 확정할 수는 없습니다. 갤러리의 평소 활동량에 맞게 기준을 설정하세요. 관측 범위 밖이거나 개념글 전용 목록에 들어오기 전의 추천 변화는 알 수 없습니다. 기준점을 소급해 추정하지 않습니다. 네트워크 요청은 봇의 일반 검사와 최소 간격을 공유하므로 이 기능을 켜면 일반 검사 속도에도 영향이 있을 수 있습니다. 메모리 관측은 봇당 최근2048글로 제한됩니다.

설정 보존
기존 봇의 설정·목록·DB·스냅샷을 유지한 채 업데이트합니다. 설치 전 기존 설정을 백업하는 것을 권장합니다. 복사하거나 설정 파일을 가져와 새로 만든 봇은 기준값은 유지하되 추천수 조작 방지는 꺼진 상태로 시작합니다. 이전 베타의 도배 최소 글자 수·제목/본문 OR 감지와 매 사이클 전체 검사 옵션도 포함됩니다.

이번 배포는 베타입니다. 정식판은1.7.0이며, 정식 승격과 갤러리 공지는 진행하지 않습니다.

검증 범위와 한계
실험실 마이너 갤러리의 테스트 탭에서 배포용 APK로 실제 BotService를 실행하고, 추천 1회를 직접 눌러 서버의 0→1 증가를 확인했습니다. 독립 관측 총 3회(일반 검사 1회 후 120초 대기 중 2회)와 봇 중지 후 관측 중단, 일반 글 보존을 확인했습니다. 시험 글과 임시 로그인 자료는 정리했습니다.

실제 개념글 해제 성공은 미검증입니다. 실험실 갤러리의 개념글 등록 기준은 10개이며 시험 글은 1개여서, 관리자 등록도 디시 서버가 기준 미달로 거절했습니다. 해제 전송·응답 확인과 실패·중복 방지는 대체 응답으로 회귀 검증했습니다. 일반 글의 관측 로그를 실제 해제 성공으로 계산하지 않았습니다. 갤러리 기준 변경이나 중복 추천은 하지 않았습니다. 사용자가 이 한계를 명시한 베타4 배포를 승인했습니다.

Android별 계측·정확한 서명 APK 업데이트·설정/DB/스냅샷 보존과 최종 빌드 상세 결과는 함께 관리되는 검증 원장에 기록합니다. 물리 기기와 장시간 운용은 검증하지 않았습니다.
