# 완장봇 v1.5.2-beta4 사용 안내

개발용 베타입니다. 업데이트 전 DB를 백업하세요. 기존 봇 설정과 기록은 유지됩니다.

## 이번 변경

- **개별 DB 사용:** 켜기·끄기만 남기고 시작 방식 선택창과 현재 DB 안내 문구를 없앴습니다.
- **작동 시간대:** 봇 상세에서는 켜고 끄며, 블록을 누르면 별도 페이지에서 시간을 편집합니다.
- **DB 필터:** 검사·차단·보류 기록에서 DB와 갤러리를 여러 개 선택할 수 있습니다.
- **DB 초기화:** 조회 필터와 별개로 전체 또는 원하는 DB들을 고릅니다.

## 개별 DB 사용

봇을 중지한 뒤 **개별 DB 사용** 스위치를 켜세요. 처음에는 빈 검사 기록으로 시작하고, 기존 개별 기록이 있으면 그대로 이어 씁니다. 끄면 공용 DB를 사용하며 개별 기록은 지우지 않습니다. 봇마다 개별 기록은 하나만 유지합니다.

화면 설명은 **검사 기록을 다른 봇과 분리하여 처리합니다.**로 변경했습니다.

차단·삭제의 중복 조치 방지와 보류 대상의 중복 등록 기준은 계속 공용입니다. 새 차단·보류 기록에는 당시 사용한 DB를 저장하므로 나중에 옵션을 바꿔도 과거 기록의 DB는 달라지지 않습니다.

## 작동 시간대

봇 상세의 **작동 시간대** 스위치로 사용 여부를 바꿉니다. 시간대를 추가·수정·삭제하려면 스위치 왼쪽의 블록을 누르세요. 별도 설정 페이지에서 편집합니다.

여러 구간과 자정을 넘는 시간대를 지원합니다. 시간대 밖에는 실행 중인 봇이 예약 대기하며, 직접 중지한 봇을 자동으로 켜는 기능은 아닙니다.

## DB·갤러리 필터

로비의 **DB** 화면에서 검사·차단·보류 기록의 깔때기 버튼을 누르세요.

- DB와 갤러리는 각각 여러 개 체크할 수 있습니다. 각 **전체**는 해당 그룹을 모두 선택합니다.
- 선택한 DB와 선택한 갤러리에 해당하는 기록을 함께 보여줍니다.
- **적용**을 누르면 반영합니다. 취소하거나 창을 닫으면 기존 선택을 유지합니다.
- 봇 상세에서 여는 기록 목록은 해당 봇이 사용하는 DB로 고정됩니다.
- 구버전 차단·보류 기록은 당시 DB를 알 수 없어 **이전 기록 (DB 범위 미상)**으로 보존합니다. 전체 또는 해당 항목에서 확인할 수 있습니다.

## DB 초기화

모든 봇을 중지한 뒤 **초기화**에서 전체 DB 또는 원하는 DB들을 고르세요. DB 목록 확인이 끝나야 **다음**을 누를 수 있으며, 목록을 불러오지 못하면 **다시 시도**하세요. 마지막 확인창에 표시된 DB 목록을 확인하고 실행합니다. 조회 중인 갤러리·검색 조건과는 별개입니다.

선택한 DB의 검사·차단·보류 기록과 다른 기록에서 사용하지 않는 스냅샷을 지웁니다. 선택하지 않은 DB의 기록은 보존합니다. 실행 중이거나 종료 처리 중인 봇이 있으면 초기화할 수 없습니다.

**공용 중복 조치 방지 정보는 초기화하지 않습니다.** 다만 보류 기록을 지운 대상은 다시 보류될 수 있습니다.

DB 백업은 조회 필터와 관계없이 전체 기록을 저장합니다.
