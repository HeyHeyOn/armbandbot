# 독립 검사 기록과 작동 시간대

기존 봇 설정과 데이터는 유지됩니다. 기존에 설정한 작동 시간대도 그대로 이어 씁니다.

봇 설정의 **갤러리 설정 자동 갱신** 아래에 **독립 검사 기록**과 **작동 시간대**가 있습니다. 두 항목은 다른 설정과 같은 형태로 정리되어 있으며, 오른쪽 스위치로 켜고 끕니다.

## 독립 검사 기록

봇 설정의 **독립 검사 기록**을 켜면 이 봇의 검사 여부·댓글 수·스냅샷 기록을 다른 봇과 분리합니다. 같은 갤러리에 서로 다른 필터를 적용하는 봇을 함께 사용할 때 유용합니다.

- 설정을 바꾸기 전에 봇을 중지하세요.
- 처음 켤 때 **공용 검사 상태에서 시작**하면 기존 공용 검사 기록을 기준으로 이어서 검사합니다.
- **빈 기록으로 시작**하면 검사 범위 안의 기존 글도 새 글처럼 검사할 수 있습니다.
- 옵션을 꺼도 독립 검사 기록은 보존됩니다. 다시 켤 때 기존 기록을 이어 쓰거나 공용 기록을 기준으로 다시 초기화할 수 있습니다.
- 봇을 복사하거나 설정을 새 봇으로 가져오면 독립 검사 옵션은 꺼진 상태로 시작합니다.

검사 기록만 분리됩니다. 차단·삭제·보류 결과와 중복 조치 방지는 공용으로 관리하므로, 같은 대상에 대한 조치가 봇 수만큼 반복되도록 하는 기능은 아닙니다.

## 작동 시간대

봇별 작동 시간대를 켜고 구간을 추가하세요. 번호가 붙은 각 구간의 시작·종료 시각을 수정하거나 구간을 삭제할 수 있습니다. 휴대폰에 설정된 현지 시간을 기준으로 매일 반복되며, 구간은 최대 64개까지 추가할 수 있습니다.

- 시작 시각부터 작동하고 종료 시각부터 대기합니다.
- `22:00~05:00`은 밤 10시부터 다음 날 새벽 5시까지 작동합니다.
- `10:00~11:00`과 `15:00~16:00`을 추가하면 두 구간에만 작동하고, 사이의 `11:00~15:00`에는 대기합니다.
- 구간이 겹치거나 맞닿으면 끊김 없이 이어서 작동합니다. 겹친 시간 때문에 검사를 중복 실행하지 않습니다.
- 시작과 종료 시각이 같은 구간은 저장할 수 없습니다. 하루 종일 작동하려면 시간대 옵션을 끄세요.
- 시간대 밖에는 실행 스위치를 켠 상태로 **예약 대기**합니다. 봇을 직접 중지한 상태와 다릅니다.
- 시간대가 끝나면 새 검사·조치를 시작하지 않습니다. 이미 서버에 보낸 조치는 결과를 기록합니다.
- 휴대폰의 시간·시간대 또는 일정 변경은 실행 중인 서비스에서 최대 60초 간격으로 다시 확인합니다.

Android가 앱 실행을 제한하거나 서비스를 종료하면 정확한 시각의 자동 재개를 보장할 수 없습니다. 복구 안내 알림이 표시되면 알림에서 앱을 다시 시작하세요.

대기 중 작성된 모든 글을 무제한으로 따라잡는 기능은 아닙니다. 재개할 때 설정된 검사 범위에서 벗어난 글은 검사하지 못할 수 있습니다.

## DB 대시보드와 백업

- 봇 상세의 검사 목록은 해당 봇이 사용하는 공용 또는 독립 기록을 보여주며, 검사 범위는 바꿀 수 없습니다.
- 로비의 DB 모니터링 검사 목록에서 **깔때기 버튼(기록 필터 설정)**을 누르세요. 기존 갤러리 선택과 검사 범위 탭 대신 **기록 필터** 창에서 갤러리와 검사 범위를 함께 고릅니다.
- 검사 범위의 **전체**는 모든 검사 기록, **공용**은 함께 쓰는 기록, 봇 이름은 해당 봇의 독립 기록을 뜻합니다. **적용**을 눌러야 목록에 반영되며, **취소**하거나 창을 닫으면 기존 선택을 유지합니다.
- 기본값인 전체 갤러리·전체 검사 범위에서는 요약을 표시하지 않습니다. 범위를 좁히면 선택한 갤러리나 검사 범위만 버튼 옆에 표시하며, **공용**을 선택한 경우에도 ‘공용’이 표시됩니다.
- 각 행에는 독립 기록일 때만 검사 범위를 표시합니다. 공용 기록에는 별도 범위 표시가 없습니다.
- 검색창의 **검색 범위 설정**은 검색할 내용의 범위를 고르는 기존 기능이며, 갤러리·검사 범위를 고르는 기록 필터와 별개입니다.
- 검사 범위를 공용 또는 특정 봇으로 적용한 뒤 초기화하면 해당 검사 범위 전체의 검사 기록을 지우며, 다른 범위와 조치 기록은 보존됩니다. 갤러리·검색 필터나 체크한 행만 지우는 기능이 아닙니다. 확인창의 검사 범위를 확인하세요.
- 검사 범위가 전체인 상태에서 초기화하면 모든 범위의 검사·차단·보류 기록, 조치 중복방지 정보와 스냅샷을 삭제합니다. 갤러리를 좁혀도 전체 DB 초기화이므로 먼저 DB를 백업하세요.
- 개별 행 삭제와 범위 초기화는 별개입니다. 조치 이력 조회는 검사 기록의 범위 선택과 별개로 전체 또는 실행한 봇 기준으로 확인합니다.
- DB 백업은 현재 필터와 관계없이 공용·독립 기록과 조치 이력을 포함한 DB 전체를 저장합니다.
- 독립 기록과 스냅샷을 지우기 전에는 DB 백업을 권장합니다.
- 기존 DB는 검사 기록을 공용 범위로 보존하며 새 형식으로 이전합니다. 기존 조치의 실행 봇을 알 수 없는 경우 이전 기록으로 구분합니다.
