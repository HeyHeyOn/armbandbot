# 독립 검사 기록과 작동 시간대

## 독립 검사 기록 사용

봇 설정의 **독립 검사 기록 사용**을 켜면 이 봇의 검사 여부·댓글 수·스냅샷 기록을 다른 봇과 분리합니다. 같은 갤러리에 서로 다른 필터를 적용하는 봇을 함께 사용할 때 유용합니다.

- 설정을 바꾸기 전에 봇을 중지하세요.
- 처음 켤 때 **공용 검사 상태에서 시작**하면 기존 공용 검사 기록을 기준으로 이어서 검사합니다.
- **빈 기록으로 시작**하면 검사 범위 안의 기존 글도 새 글처럼 검사할 수 있습니다.
- 옵션을 꺼도 독립 검사 기록은 보존됩니다. 다시 켤 때 기존 기록을 이어 쓰거나 공용 기록을 기준으로 다시 초기화할 수 있습니다.
- 봇을 복사하거나 설정을 새 봇으로 가져오면 독립 검사 옵션은 꺼진 상태로 시작합니다.

검사 기록만 분리됩니다. 차단·삭제·보류 결과와 중복 조치 방지는 공용으로 관리하므로, 같은 대상에 대한 조치가 봇 수만큼 반복되도록 하는 기능은 아닙니다.

## 작동 시간대

봇별 작동 시간대를 켜고 시작·종료 시각을 설정합니다. 휴대폰에 설정된 현지 시간을 기준으로 매일 반복됩니다.

- 시작 시각부터 작동하고 종료 시각부터 대기합니다.
- `22:00~06:00`처럼 다음 날 끝나는 구간도 사용할 수 있습니다.
- 시작과 종료 시각은 서로 달라야 합니다. 하루 종일 작동하려면 시간대 옵션을 끄세요.
- 시간대 밖에는 실행 스위치를 켠 상태로 **예약 대기**합니다. 봇을 직접 중지한 상태와 다릅니다.
- 시간대가 끝나면 새 검사·조치를 시작하지 않습니다. 이미 서버에 보낸 조치는 결과를 기록합니다.
- 휴대폰의 시간·시간대 또는 일정 변경은 실행 중인 서비스에서 최대 60초 간격으로 다시 확인합니다.

Android가 앱 실행을 제한하거나 서비스를 종료하면 정확한 시각의 자동 재개를 보장할 수 없습니다. 복구 안내 알림이 표시되면 알림에서 앱을 다시 시작하세요.

대기 중 작성된 모든 글을 무제한으로 따라잡는 기능은 아닙니다. 재개할 때 설정된 검사 범위에서 벗어난 글은 검사하지 못할 수 있습니다.

## DB 대시보드와 백업

- 봇 상세의 검사 목록은 해당 봇이 사용하는 공용 또는 독립 기록을 보여줍니다.
- 로비의 DB 대시보드에서는 전체 검사 기록을 확인할 수 있습니다.
- 검사 기록 초기화와 조치 이력 삭제는 서로 다른 작업입니다. 확인창의 대상 범위를 확인하세요.
- 독립 기록과 스냅샷을 지우기 전에는 DB 백업을 권장합니다.
- 기존 DB는 검사 기록을 공용 범위로 보존하며 새 형식으로 이전합니다. 기존 조치의 실행 봇을 알 수 없는 경우 이전 기록으로 구분합니다.

> 개발 중 사용자 안내 초안입니다. 배포 전 실제 UI와 검증 결과를 대조해야 하며, 이 파일 작성만으로 온라인 매뉴얼이 갱신되지는 않습니다.
