# 개별 DB와 작동 시간대

기존 봇 설정과 기록은 유지됩니다. 설정 순서는 갤러리 설정 자동 갱신 → 개별 DB 사용 → 작동 시간대입니다.

## 개별 DB 사용

설명: 검사 기록을 다른 봇과 분리하여 처리합니다.

- 봇을 중지한 뒤 오른쪽 스위치로 켜고 끕니다. 시작 방법을 고르는 창은 없습니다.
- 각 봇은 하나의 고정된 개별 DB를 사용합니다. 처음에는 빈 검사 기록으로 시작하고, 이미 기록이 있으면 그대로 이어 씁니다. 공용 기록을 복사하거나 기존 개별 기록을 덮어쓰지 않습니다.
- 끄면 공용 DB를 사용하지만 개별 기록은 보존됩니다. 다시 켜도 같은 기록을 사용합니다.
- 봇을 복사하거나 설정을 새 봇으로 가져오면 개별 DB 옵션은 꺼진 상태로 시작합니다.
- 실제로 실행 중이거나 종료 처리 중인 봇의 DB 범위는 바꿀 수 없습니다.

차단·삭제의 중복 조치 방지는 계속 공용입니다. 보류 대상의 중복 등록 기준도 DB별로 나누지 않습니다. 새 조치·보류 기록에는 당시 사용한 DB와 실행한 봇을 각각 저장하므로, 나중에 스위치를 바꿔도 과거 기록의 소속 DB가 바뀌지 않습니다.

## 작동 시간대

상세 화면에는 작동 시간대 스위치만 표시합니다. 카드 본문을 누르면 별도의 전체 화면 설정 페이지로 이동하며, 그곳에서 구간을 추가·수정·삭제합니다. 스위치만 눌러서는 페이지가 열리지 않습니다.

- 휴대폰의 현지 시간을 기준으로 매일 반복하며 최대 64개 구간을 저장합니다.
- 시작 시각부터 작동하고 종료 시각부터 대기합니다. `22:00~05:00`은 다음 날 새벽까지 작동합니다.
- 떨어진 구간 사이에는 대기하고, 겹치거나 맞닿은 구간에서는 끊김 없이 작동합니다.
- 시작과 종료가 같은 구간은 저장할 수 없습니다. 하루 종일 작동하려면 시간대 옵션을 끄세요.
- 시간대 밖에는 실행 스위치를 켠 상태로 예약 대기합니다. 이미 서버에 보낸 조치는 결과를 기록하지만 시간대가 끝나면 새 검사·조치를 시작하지 않습니다.
- 시간·시간대·일정 변경은 실행 중인 서비스에서 최대 60초 간격으로 확인합니다.

Android의 실행 제한이나 서비스 종료 시 정확한 시각의 재개는 보장되지 않습니다. 대기 중 작성된 글도 재개 시 검사 범위를 벗어나 있으면 검사하지 못할 수 있습니다.

## DB 조회와 백업

- 로비에서 여는 화면의 제목은 DB입니다. 깔때기 버튼의 기록 필터에서 여러 DB와 여러 갤러리를 체크합니다. 선택한 DB 중 하나에 속하면서 선택한 갤러리 중 하나에 속하는 기록을 보여줍니다.
- 각 항목의 전체는 해당 목록을 모두 선택합니다. 검사·차단 상세·보류 기록에 동일한 필터가 적용되며, 검사 기록 없이 조치나 보류 기록만 있는 DB·갤러리도 목록에 나타납니다.
- 적용을 눌러야 반영됩니다. 취소, Android 뒤로, 창 밖 누르기는 변경 중인 선택을 버리고 기존 선택을 유지합니다.
- 전체가 아닌 조건만 버튼 옆에 표시합니다. 공용만 선택한 경우에는 공용을 표시합니다. 검색할 내용의 종류를 고르는 검색 범위 설정은 별개입니다.
- 봇 상세에서 여는 목록은 그 봇이 사용하는 DB로 시작하며 DB 선택은 고정됩니다.
- 공용 기록의 행에는 DB 표시를 반복하지 않습니다. 개별 기록에는 DB를 표시하고, 조치·보류 행의 실행 봇 정보는 별도로 유지합니다.
- 예전 조치·보류 기록의 당시 DB를 알 수 없으면 이전 기록 (DB 범위 미상)으로 표시합니다. 현재 봇 설정으로 추정하지 않습니다. 내부 범위 값은 LEGACY이며 기존 행은 삭제하지 않습니다.
- DB 백업은 조회 필터와 관계없이 전체 기록을 저장합니다. 새 백업은 기록 당시 DB도 보존하며, 그 정보가 없는 예전 백업은 DB 범위 미상으로 가져옵니다.

## DB 초기화

- 조회 필터와 별개로 전체 DB 또는 선택한 DB를 직접 지정합니다. 아무것도 선택하지 않으면 진행할 수 없습니다.
- 다음을 누른 뒤 표시되는 확인창의 DB 목록이 실제 삭제 대상입니다. 확인창이 열린 후 다른 DB가 생겨도 삭제 대상이 자동으로 늘어나지 않습니다.
- 선택한 DB의 검사·조치·보류 기록을 지웁니다. 다른 DB의 행과 그 행이 참조하는 스냅샷은 보존합니다. 삭제된 기록만 참조하던 스냅샷은 정리합니다.
- 공용 중복 조치 방지 정보는 초기화하지 않습니다. 다만 삭제한 보류 행이 제공하던 중복 보류 억제는 사라져 해당 대상이 다시 보류될 수 있습니다.
- 실행 중이거나 종료 처리 중인 봇이 있으면 초기화를 거절합니다. 모든 봇을 중지한 뒤 확인하세요.
- 초기화 전 DB 백업을 권장합니다. 개별 행 삭제는 DB 초기화와 별개입니다.
