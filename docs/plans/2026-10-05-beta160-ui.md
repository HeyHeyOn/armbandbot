# 1.6.0-beta2 — 상세 화면과 키워드 목록

기준: `c7687a2` / 1.6.0-beta1, 새 버전: 1.6.0-beta2 / code181.

## 사용자 변화

- 예약 끌올·자동 탭 분류와 기존 필터 상세 화면이 같은 상단 컴포넌트를 사용한다.
- 자동 탭 분류의 갤러리 선택, 규칙 작성, 저장된 규칙을 카드로 구분한다. 일반·우회 키워드는 각각 큰 줄바꿈 편집창으로 입력하며, 한 규칙에서 두 목록 중 어느 하나가 일치하면 적용한다.
- 금지어·유동 필터의 봇 상세 행과 각 상세 화면 상단에 마스터 토글을 추가한다. 끄면 하위 입력이 흐려지고 비활성화되며, 저장된 설정은 유지된다.

## 데이터·실행 계약

기존 `keyword` 문자열은 일반 키워드 한 항목으로 읽는다. 새 JSON은 `normalKeywords`·`bypassKeywords` 배열을 저장한다. 기존 규칙 ID·순서·갤러리·대상 탭·비활성 상태를 보존한다. 키워드 내 `#` 등 특수문자는 리터럴로 유지한다. 일반은 기존 금지어와 같은 대소문자 무시 부분 문자열, 우회는 `ModerationTextRules`의 기본 우회 판정을 사용한다. 금지어 필터의 별도 강화 옵션과 적용 대상 제한은 자동 분류 설정에 전파하지 않는다.

갤러리 변경은 이전 편집 초안을 버린다. 팝업 확인은 초안만 바꾸며 규칙 추가/수정 저장 시에만 영구 저장한다. 기존 화이트리스트·예외·조치 우선순위·다중 봇 claim·권한 확인은 유지한다.

두 필터 마스터는 이전 동작을 유지하도록 기본 true. 런타임 구성 로드에서 로컬·원격 금지어 병합 뒤 적용 목록을 비우고 유동 하위 옵션을 false로 제한한다. 원본 목록·하위 값은 변경하지 않는다. 토글 변경은 기존 bounded 재검사 revision을 갱신하며, 유동 동영상 필터 재활성화 시 전용 재검사도 예약한다. 복사/가져오기는 마스터 상태와 규칙을 보존하되 자동 실행·런타임 revision은 복제하지 않는다.

거대한 BotDetailScreen에 새 상태를 추가하지 않고 FilterMasterEntry/Section에 상태를 분리한다. DB schema와 스냅샷 경로는 변경하지 않는다.

- Debug/Release 전체 JVM·classic UAST lint, signed APK metadata·서명·DEX.
- API24/35 격리 guest에서 exact signed beta1→beta2 업데이트, Room 행·스냅샷·설정 보존, light/dark 화면과 편집/재진입.
- 승인된 laboratory1 관리 세션으로 실제 탭을 읽고 비활성 규칙을 저장한다. 이번 검증은 서버 게시·차단·삭제·탭 이동을 수행하지 않는다.
